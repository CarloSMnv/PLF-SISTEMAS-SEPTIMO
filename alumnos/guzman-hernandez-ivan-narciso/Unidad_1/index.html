Paradigmas de Programación

Modelos fundamentales que determinan la forma en que se estructura, organiza y ejecuta el código.

Paradigma Imperativo

Enfoque: Describe el cómo. Se basa en secuencias de instrucciones que cambian el estado del programa paso a paso.

Prog. Estructurada / Procedural

Divide el programa en rutinas usando estructuras secuenciales e iterativas.

Lenguajes: C, Pascal, Fortran

Prog. Orientada a Objetos (POO)

Modela el problema agrupando el estado y comportamiento en "objetos".

Lenguajes: Java, C++, C#

Paradigma Declarativo

Enfoque: Describe el qué. Especifica el resultado o la lógica del problema sin detallar el control de flujo.

Programación Funcional

Basada en la evaluación de funciones matemáticas puras. Evita el estado mutable y favorece la recursividad.

Lenguajes: Haskell, Lisp, Scheme

Programación Lógica

El programa es una base de hechos y reglas; la ejecución es una demostración de teoremas por inferencia.

Lenguajes: Prolog, Datalog
